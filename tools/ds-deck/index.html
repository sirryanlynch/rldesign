Weeks 7–10  ·  scope

05Applied Surfaces
Weeks 9–11  ·  scope
  • Product UI application across canvas and dashboard
  • Marketing website application
  • Developer-relations social templates
06Brand Book & Handoff Kit
Weeks 11–12  ·  scope
  • Brand book: usage, do/don’t, accessibility notes
  • Figma component set with component definitions
  • Versioned asset library plus final QA pass
