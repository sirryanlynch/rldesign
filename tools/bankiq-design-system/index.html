14 — Scrim
The project term for any gradient mask that fades content at the edge of a scrollable region, signalling there's more off-screen. Implemented via mask-image: linear-gradient(...) rather than an overlaid element, so it follows the scroll container's actual background. Used at both horizontal (Quick Insights rail) and vertical (NLQ dock above the input) edges.

22 — Modal Escape + Focus Trap
Behavior contract — not a CSS component. A single global keydown listener handles Escape across all modals in last-opened-wins priority order. A MutationObserver watches each registered modal root for the .open class and pulls keyboard focus to the first focusable child when opened.

Listener · single document keydown at module scope

23 — Selection With Muted Peers
Core design principle. When one card in a group is selected, the chosen card receives a subtle elevation (lighter background, stronger stroke, soft shadow) while peers visually recede — denser padding, dimmer text, muted product icon. Never decorate the chosen card with brand color; contrast comes from the peers stepping back. No gold ring, no accent border on the selected item.
